KHUSHI SHARMA PORTFOLIO

FILES
- index.html: Website content and structure
- style.css: Complete design and responsive layout
- script.js: Animations, navigation, clock, counters, and email copy
- Khushi_Sharma_Resume.pdf: Résumé opened by the website
- favicon.svg: Browser-tab icon

HOW TO HOST
1. Keep all five files together in the same folder.
2. Upload the folder contents to Netlify, GitHub Pages, Vercel, cPanel, or another static host.
3. Make sure index.html stays at the top level.

NETLIFY
Drag this entire folder into Netlify Drop. No build command or publish directory is required.

LOCAL PREVIEW
Double-click index.html to open it in a browser. For the most accurate preview, use a simple local web server.
